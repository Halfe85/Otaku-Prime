Otaku Prime 0.1.2 Alpha5
========================

AniList request handling:
- Replaced one-request-per-title franchise resolution with batched AniList ID queries.
- Fetch up to 50 media records in each AniList relation request.
- Resolve prequel frontiers in batches without fetching unneeded sequel records.
- Added a shared AniList request limiter across import, relation, and release services.
- Honor AniList HTTP 429 retry timing before retrying a request.

Testing:
- Added coverage for multi-request AniList relation batching.
- Verified the batched query against the live AniList GraphQL API.
