Otaku Prime 0.1.2 Alpha8b
=========================

Alpha8b supersedes Alpha8 and includes all Alpha8 work below.

- Improve TheTVDB matching for anime with non-Latin primary titles by using title aliases without treating plot overviews as aliases.
- Search conservative base-title variants when AniList franchise or season names end in numbered season, part, or cour suffixes.

Kodi database adoption:
- Make verified TMDB or TheTVDB configuration the mandatory gate before watchlist processing.
- Inventory Kodi TV shows and episodes before importing or resolving watchlist content.
- Treat an available but empty Kodi video library as a valid database ready for Prime content.
- Persist Kodi inventory state, provider IDs, playback paths, and local-versus-plugin origin.
- Add a Prime/Kodi ownership registry with local, external, pending, and Prime ownership states.
- Match resolved episodes by provider episode ID, then provider show ID plus season/episode number.
- Give existing local files unconditional priority over Prime streaming projections.
- Mark missing episodes as pending Prime projections and expose Kodi status/ownership through the authenticated admin API.
- Disable legacy source registration, `.strm` publication, and library scanning while direct `plugin://` projection replaces them.

Application logging:
- Centralize INFO, WARNING, and ERROR logging for Kodi and Prime's SQLite-backed admin log window.
- Capture unhandled main-thread and background-thread exceptions with tracebacks.
- Log startup stages, watchlist gates/importers/processors, metadata resolution, Kodi inventory, ownership reconciliation, and web configuration failures.

Metadata matching fixes:
- Preserve TheTVDB aliases and translated search names when the provider's primary series title uses another script or language.
- Search every available AniList franchise title and de-duplicate provider results instead of stopping on the first non-empty but unrelated result set.
- Treat standalone/main-series ONA entries as numbered TV seasons; reserve season 00 for ONA side stories, parent-linked extras, and spin-offs.

Metadata authority:
- Add mandatory TMDB and TheTVDB v4 resolver connections using credentials supplied by each Prime installation.
- Store the selected resolver globally so Prime's Kodi library uses one numbering authority.
- Block all watchlist fetching until TMDB or TheTVDB has been configured and verified.
- Require the matching Kodi TV information scraper and offer to install it when missing.

Franchise and episode resolution:
- Resolve Prime franchises to the selected provider's TV show identity.
- Resolve normal seasons while retaining provider-specific season names when they differ from the franchise title.
- Store provider show, season, and episode identities separately from AniList and Prime's internal identities.
- Resolve Season 00 episode numbers from the metadata provider instead of inventing S00E numbers from AniList ordering.
- Keep ambiguous specials unresolved and unpublished until a unique provider match is available.

Web settings:
- Put Information Resolver at the top of Watchlist Accounts as a mandatory setup step.
- Support TMDB API Read Access Token/API key and TheTVDB v4 project API key with optional subscriber PIN.
- Never render stored resolver credentials back into the web interface.

Testing:
- Add regression coverage for named seasons, normal episode mapping, S00E07 special mapping, ambiguous-special blocking, and the mandatory watchlist gate.
